# Website-aligned mobile branding

Verified against https://www.nathonline.com.np/ and src/site.css on 1 October 2026.

Both previews reuse the unmodified src/assets/nath-logo.png and the site's light palette: royal blue #124BDD, navy #101E48, background #F7F9FF, muted text #53617E and card borders #D8E2F5. Primary actions use blue fills and 7-point corners; service surfaces use white and rounded corners. System sans-serif fonts provide native language/accessibility support in place of the website's Inter/Arial stack.

The app homepage adopts “Forms, bills & bookings. With personal help.” and the site's Butwal-team introduction. Mobile navigation retains customer preparation, request/tracking and protected staff access. Preview endpoints and data handling are unchanged. The public website is not modified.

Version 0.3 is a development preview, not a store release. Existing real-device, signing and store-acceptance gates still apply.
